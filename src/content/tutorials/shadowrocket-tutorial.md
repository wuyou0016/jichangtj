小火箭（Shadowrocket）是 iPhone 和 iPad 上最常用的机场客户端，导入订阅、选节点、一键连接，操作比较简单。下面按"下载 → 添加订阅 → 连接 → 设置路由"的顺序讲。不同版本界面文字可能略有差异，入口位置基本一致。

## 第一步：下载小火箭

小火箭在中国大陆地区的 App Store 已经下架，需要用**其他国家或地区的 Apple ID** 登录 App Store 才能搜到并购买（付费应用，价格以 App Store 为准）。

关于 Apple ID 的安全提醒：

- 用自己注册的外区 Apple ID 最稳妥。
- 如果用别人提供的共享账号，**只在 App Store 里登录，不要在"设置 → Apple ID / iCloud"里登录**，否则可能被远程锁定设备或同步走你的数据。

## 第二步：添加机场订阅

**方法一：复制后自动识别（最简单）**

1. 在机场用户中心复制订阅链接。很多机场的"一键订阅"里有专门的 **Shadowrocket** 选项，优先选它。
2. 打开小火箭，它会识别剪贴板里的链接，弹窗询问是否添加，点「添加」。

**方法二：手动添加**

1. 打开小火箭，点首页右上角的「+」。
2. "类型"选择「Subscribe」。
3. "URL"粘贴订阅链接，"备注"填个方便识别的名字（比如机场名）。
4. 点右上角「完成」。

添加成功后，首页会出现这份订阅和下面的节点列表。

## 第三步：连接

1. 在节点列表里点一个节点，前面出现选中标记。
2. 打开首页最上方的连接开关。
3. **第一次连接**时，系统会提示"Shadowrocket 想添加 VPN 配置"，点「允许」，再输入手机密码或用面容 ID 确认。
4. 开关变成已连接、状态栏出现 VPN 图标，就说明连上了。

首页底部的「连通性测试」可以一次测所有节点的延迟，优先选延迟低、没有超时的节点。

## 第四步：设置全局路由

首页的「全局路由」决定流量怎么走：

- **配置**：按订阅里的规则分流，国内网站直连、国外网站走代理。**日常推荐用这个**。
- **代理**：所有流量都走代理，相当于全局模式，适合临时排查问题。
- **直连**：所有流量都不走代理。
- **场景**：按网络环境（Wi-Fi / 蜂窝网络）自动切换，一般用不到。

几种模式的思路和电脑上 Clash 的"规则 / 全局 / 直连"是一样的，详细解释见[Clash 规则模式、全局模式与 TUN 模式详解](/tutorials/clash-proxy-modes-tun/)。

## 更新订阅

机场换了节点之后需要更新订阅：在首页的订阅名称上左滑，点「更新」即可。设置里的订阅相关选项还可以开启打开应用时自动更新。

## 常见问题

**添加订阅后没有节点？**
先检查链接是否复制完整、是否过期；再确认用的是 Shadowrocket 或通用格式的订阅；还不行就切换到蜂窝网络再更新一次。

**连上了但网页打不开？**
先换两三个节点试试；再确认「全局路由」选的是"配置"或"代理"而不是"直连"；最后检查是否同时开着其他 VPN 应用——iPhone 同一时间只能有一个 VPN 配置生效。

**连接开关一打开就自动断开？**
通常是 VPN 配置没有正确安装：到「设置 → 通用 → VPN 与设备管理」里删除 Shadowrocket 的 VPN 配置，回到小火箭重新连接一次，按提示重新允许。

更多排查思路见[常见问题排查](/tutorials/common-connection-problems/)。还没选好机场的话，可以先看[机场推荐排行榜](/rankings/)。
