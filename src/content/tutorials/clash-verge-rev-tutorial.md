Clash Verge Rev 是目前 Windows 和 macOS 上最常用的 Clash 客户端之一。它是原 Clash Verge 停更后由社区继续维护的版本，使用 Mihomo 内核（原名 Clash Meta），兼容机场提供的 Clash 订阅。Clash for Windows 停更之后，大多数人都换到了它。

这篇按"下载 → 导入订阅 → 选节点 → 开代理"的顺序讲一遍。不同版本的界面文字可能略有差异，但入口位置基本一致。

## 第一步：下载对应的安装包

到 GitHub 上 `clash-verge-rev/clash-verge-rev` 项目的 **Releases** 页面下载最新版本。按你的系统选文件：

| 系统 | 选择文件名里带这些字样的 |
| --- | --- |
| Windows 64 位（绝大多数电脑） | `x64-setup.exe` |
| Windows ARM 设备 | `arm64-setup.exe` |
| macOS，Apple 芯片（M1 及之后） | `aarch64.dmg` |
| macOS，Intel 芯片 | `x64.dmg` |
| Linux | `.deb` 或 `.rpm`，按发行版选择 |

不确定 Mac 是什么芯片：点左上角苹果图标 →「关于本机」，"芯片"一栏写着 Apple M 系列就是 Apple 芯片。

安装时可能遇到两个提示：

- **Windows 提示"已保护你的电脑"**：点「更多信息」→「仍要运行」。
- **macOS 提示"已损坏，无法打开"**：这是系统对未公证应用的拦截，把应用拖进"应用程序"文件夹后，打开"终端"执行 `sudo xattr -r -c /Applications/Clash\ Verge.app`，输入开机密码后再打开即可。

请只从 GitHub Releases 下载。搜索结果里很多"Clash Verge 官网""中文版下载站"并不是项目官方，安装包来源无法确认。

## 第二步：导入机场订阅

1. 登录机场官网的用户中心，找到"一键订阅"或"复制订阅链接"，选择 **Clash** 格式复制。
2. 打开 Clash Verge Rev，点左侧的「订阅」。
3. 在页面顶部的输入框里粘贴订阅链接，点「导入」。
4. 导入成功后，下方会出现一张订阅卡片，通常能看到已用流量和到期时间。
5. **点击这张卡片，让它处于选中（高亮）状态**——只有选中的订阅才会生效，这是新手最容易漏掉的一步。

如果提示导入失败，先检查链接有没有复制完整、有没有过期；更多排查方法见[常见问题排查](/tutorials/common-connection-problems/)。

## 第三步：选择节点

1. 点左侧的「代理」。
2. 页面顶部可以切换「规则 / 全局 / 直连」三种模式，**日常用"规则"就行**：国内网站直连、国外网站走代理，既快又省流量。三种模式的区别见[Clash 规则模式、全局模式与 TUN 模式详解](/tutorials/clash-proxy-modes-tun/)。
3. 展开机场配置好的节点分组（名字由机场决定，常见的是"节点选择""Proxy"之类），点一个节点即可切换。
4. 分组旁边的闪电图标可以批量测延迟，优先选延迟低、没有超时的节点。

## 第四步：开启系统代理

1. 点左侧的「设置」，打开「系统代理」开关（新版首页也有快捷开关）。
2. 打开浏览器访问一个国外网站，能正常打开就说明配置成功了。

**什么时候需要 TUN 模式？** 系统代理只对"愿意走系统代理"的程序生效，浏览器没问题，但部分游戏、命令行工具、桌面应用会绕过它。这时可以打开设置里的「虚拟网卡模式」（也就是 TUN 模式），它会接管整台电脑的网络流量：

- Windows 需要先安装「服务模式」，设置页里 TUN 开关附近会有安装入口，按提示授权即可。
- macOS 开启时会要求输入开机密码授权。

TUN 模式和其他 VPN 软件可能冲突，同一时间只开一个。

## 推荐的几个设置

- **开机自启**：设置里打开「开机自启」，配合「静默启动」可以开机后自动在后台运行。
- **订阅自动更新**：右键订阅卡片 →「编辑信息」，可以设置更新间隔（单位是分钟），机场换节点后会自动同步。
- **手动更新订阅**：右键订阅卡片 →「更新」。

## 常见问题

**开了系统代理，网页还是打不开？**
按顺序检查：订阅卡片是否选中 → 当前节点延迟测试是否超时（换两三个节点试试）→ 是否同时开着其他代理或 VPN 软件。

**关掉 Clash Verge Rev 之后电脑上不了网？**
这通常是系统代理没被还原：客户端异常退出时，系统里仍然指向一个已经不存在的代理地址。重新打开 Clash Verge Rev 把「系统代理」关掉再退出即可；也可以手动关闭——Windows 在「设置 → 网络和 Internet → 代理」里关闭"使用代理服务器"，macOS 在「系统设置 → 网络 → 当前网络 → 详细信息 → 代理」里取消勾选。

**TUN 模式打不开？**
Windows 上先确认服务模式已安装成功；如果装着其他 VPN 或加速器软件，先关掉它们再试。
