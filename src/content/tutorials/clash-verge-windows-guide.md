## Clash Verge 是什么

Clash Verge 是基于 Clash 内核（现在主要用的是 Mihomo 内核）开发的桌面客户端，界面比早期的 Clash for Windows 更现代，功能也更完善，是目前 Windows 平台最常用的机场客户端之一。如果你还不清楚"订阅链接"是什么，建议先看[客户端与订阅导入总览教程](/tutorials/client-setup-and-subscription-import/)。

## 第一步：下载安装

Clash Verge 是开源项目，建议从项目官方 GitHub 仓库的 Release 页面下载最新版本，选择 Windows 对应的安装包（通常是 `.exe` 或 `.msi` 格式）。不建议从来源不明的网站下载，避免安装到被篡改过的版本。

安装完成后首次打开，界面主要分几块：左侧是功能导航（订阅、代理、规则、日志、设置等），主区域显示当前状态。

## 第二步：导入订阅链接

1. 打开 Clash Verge，找到"订阅"（Profiles）页面。
2. 点击"新建"或"+"，选择"从 URL 导入"，把服务商给你的订阅链接粘贴进去。
3. 点击确认，客户端会自动下载并解析订阅内容，成功后会显示节点数量。
4. 点击这个订阅，将其设为"当前使用"的配置。

如果导入后节点数量是 0，先检查链接有没有复制完整（订阅链接通常很长，容易漏掉末尾字符），确认无误后再联系服务商客服确认链接是否有效。

## 第三步：选择代理模式

Clash Verge 在"代理"页面里可以看到分组的节点列表，常见几种全局模式：

- **规则模式（Rule）**：根据内置或自定义规则，自动判断哪些流量走代理、哪些直连，是日常使用最推荐的模式，国内网站直连、需要代理的流量走节点，兼顾速度和覆盖面。
- **全局模式（Global）**：所有流量都走代理节点，适合需要测试某个节点整体表现，或者规则模式下某些网站访问异常时临时切换。
- **直连模式（Direct）**：所有流量都不走代理，相当于临时关闭代理效果。

新手建议默认用规则模式，遇到具体网站访问异常再针对性调整规则或切换全局模式测试。

## TUN 模式是什么，要不要开

TUN 模式（虚拟网卡模式）会接管系统全部网络流量，包括一些普通系统代理模式覆盖不到的流量（比如某些不遵循系统代理设置的软件、游戏）。开启 TUN 模式通常需要以管理员身份运行客户端。

- 如果只是日常网页浏览、视频观看，规则模式配合系统代理通常已经够用，不需要开 TUN 模式。
- 如果发现某个特定软件或游戏死活代理不生效，可以尝试开启 TUN 模式测试是否解决问题。
- TUN 模式接管的流量范围更广，也更容易和其他网络工具（比如某些安全软件、虚拟网卡驱动）冲突，遇到网络异常先检查是不是 TUN 模式导致的。

## 常见问题

- **订阅更新后节点还是旧的**：确认是否点击了"更新"按钮，部分订阅有更新频率限制，服务商可能限制短时间内重复更新。
- **能连上但网页打不开**：检查规则模式下该网站是否被规则分类成了"直连"，可以尝试切换到全局模式测试是否是规则配置问题。
- **更多连接异常排查**，可以看[常见连接问题排查](/tutorials/common-connection-problems/)这篇文章。
