v2rayN 是 Windows 上常用的 v2ray 系客户端，开源免费，支持 Xray 和 sing-box 内核，能导入机场的通用订阅。如果你习惯 Clash，也可以直接看[Clash Verge Rev 使用教程](/tutorials/clash-verge-rev-tutorial/)。v2rayN 更新比较频繁，不同版本的菜单文字可能略有差异，下面以常见的中文界面为准。

## 第一步：下载

到 GitHub 上 `2dust/v2rayN` 项目的 **Releases** 页面下载 Windows 版本压缩包：

- 推荐选文件名里带 **SelfContained** 的版本，已经内置了 .NET 运行环境，不需要另外安装。
- 下载后解压到一个固定的文件夹（比如 `D:\v2rayN`），双击 `v2rayN.exe` 运行，不需要安装。

不要放在"下载"之类经常清理的文件夹里，以免误删配置。请只从 GitHub Releases 下载。

## 第二步：添加机场订阅

1. 在机场用户中心复制 **通用订阅** 或 **V2Ray 订阅** 链接（注意不是 Clash 订阅）。
2. 打开 v2rayN，点顶部菜单「订阅分组」→「订阅分组设置」。
3. 点「添加」，"备注"填个方便识别的名字，"可选地址 (url)"粘贴订阅链接，点「确定」保存。
4. 回到主界面，点「订阅分组」→「更新全部订阅（不通过代理）」。

更新完成后，主界面列表里会出现机场的节点。

## 第三步：选择节点

1. 先测一下延迟：全选节点（Ctrl + A）后右键，选择「测试服务器真连接延迟」，等结果出来。
2. 选一个延迟低、没有超时的节点，按回车或右键选择「设为活动服务器」。

## 第四步：开启系统代理

1. 在窗口底部（或右下角托盘图标的右键菜单）找到「系统代理」，选择 **自动配置系统代理**。
2. 路由选择 **绕过大陆**：国内网站直连、国外网站走代理，和 Clash 的"规则模式"是一个意思。
3. 打开浏览器访问一个国外网站测试。

系统代理几个选项的含义：

- **自动配置系统代理**：v2rayN 接管系统代理，日常用这个。
- **清除系统代理**：关闭代理。
- **不改变系统代理**：v2rayN 不动系统设置，适合手动给某个软件单独设置代理的人。

**需要让游戏、命令行工具也走代理？** 可以打开窗口底部的「启用 Tun」开关，它会接管整台电脑的流量，需要以管理员身份运行 v2rayN。系统代理和 TUN 的区别见[Clash 规则模式、全局模式与 TUN 模式详解](/tutorials/clash-proxy-modes-tun/)，原理是相通的。

## 常见问题

**更新订阅后列表是空的？**
检查复制的是不是通用 / V2Ray 格式的订阅；链接是否完整、是否过期。

**打开 v2rayN 被杀毒软件拦截？**
代理类软件经常被误报，确认是从 GitHub Releases 下载的就可以把文件夹加入杀毒软件的信任列表。

**退出 v2rayN 后电脑上不了网？**
系统代理没被清除。重新打开 v2rayN，把「系统代理」改成"清除系统代理"再退出；或者在 Windows「设置 → 网络和 Internet → 代理」里手动关闭"使用代理服务器"。

更多排查思路见[常见问题排查](/tutorials/common-connection-problems/)。还没选好机场的话，可以先看[机场推荐排行榜](/rankings/)。
