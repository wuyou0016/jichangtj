## 订阅导入失败或节点数量为 0

1. **确认链接完整**：订阅链接经常很长，复制时容易漏掉末尾字符，重新完整复制一遍。
2. **确认链接没过期**：部分服务商的订阅链接有有效期，或者需要定期在官网重新生成，过期后无法更新。
3. **换一个网络环境试试**：极少数情况下，获取订阅链接这个请求本身也会被干扰，换一个网络（比如手机流量）测试是否能正常获取。
4. **检查客户端是否支持该订阅格式**：不同客户端支持的订阅格式（Clash 配置、sing-box 配置、通用订阅协议等）不完全一样，确认服务商提供的格式和你用的客户端匹配。

## 明明连上了，但网页打不开

1. **确认系统代理/TUN 模式已经开启**：很多客户端需要手动开启"系统代理"或"TUN 模式"，只是软件里显示"已连接"不代表流量真的走了代理。两者的区别见[Clash 规则模式、全局模式与 TUN 模式详解](/tutorials/clash-proxy-modes-tun/)。
2. **换一个节点再试**：单个节点故障很常见，不代表整个订阅有问题，换 2-3 个节点分别测试。
3. **确认目标网站本身没问题**：偶尔是目标网站自己不可访问，可以先测试访问其他网站排除这个可能。

## 退出客户端之后，电脑上不了网

客户端异常退出时，系统代理设置可能没被还原，仍然指向一个已经不存在的代理地址，于是所有网页都打不开：

1. **重新打开客户端**，把"系统代理"关掉，再正常退出。
2. **或者手动关闭系统代理**：Windows 在「设置 → 网络和 Internet → 代理」里关闭"使用代理服务器"；macOS 在「系统设置 → 网络 → 当前网络 → 详细信息 → 代理」里取消勾选。

## 游戏或命令行工具不走代理

只开系统代理时，很多游戏和命令行工具会绕过它。需要让这些程序走代理，可以开启客户端的 TUN 模式（虚拟网卡模式），具体见[Clash 规则模式、全局模式与 TUN 模式详解](/tutorials/clash-proxy-modes-tun/)。

## 能连上，但速度很慢

1. **换节点、换协议**：不同节点、不同协议（比如 Shadowsocks、Trojan、VLESS）在同一段时间的表现可能差异很大，多测几个。
2. **确认不是高峰期拥堵**：晚上用网高峰期，很多线路会明显变慢，这是行业普遍现象，不一定是服务商的问题。
3. **对照本站的丢包率数据**：如果某个服务商的持续跟踪数据显示丢包率长期偏高，速度慢可能是线路本身的问题，可以在[机场实测数据](/tests/)里横向对比，或在[机场导航](/airports/)里查看该服务商的具体数据。
4. **如果长期、稳定地慢**：可以联系客服反馈，或者考虑该服务商是否适合你的场景——比如[远程办公场景页](/scenarios/remote-work/)里提到的持续观察思路。

## 不知道该选哪个节点

- **先看地区**：访问哪个地区的服务，通常选对应或邻近地区的节点延迟更低（比如访问日本的内容优先试日本节点）。
- **看延迟数字**：客户端里的延迟测试数字越低越好，但也要结合实际打开网页的体验，延迟低不代表一定流畅。
- **不确定就多测几个**：机场订阅通常有多个节点，没有"绝对最优"这一说，实际测试比猜测靠谱。
