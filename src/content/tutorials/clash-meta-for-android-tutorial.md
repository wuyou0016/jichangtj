Clash Meta for Android（常简称 CMFA）是安卓上最常用的 Clash 客户端，开源免费，使用 Mihomo 内核，机场给的 Clash 订阅可以直接导入。下面按"下载 → 导入订阅 → 启动 → 选节点"的顺序讲。不同版本界面文字可能略有差异，入口位置基本一致。

## 第一步：下载安装

到 GitHub 上 `MetaCubeX/ClashMetaForAndroid` 项目的 **Releases** 页面下载 APK：

- 大多数 2017 年以后的手机：选文件名带 `arm64-v8a` 的版本。
- 不确定手机架构：选带 `universal` 的通用版本，体积稍大但都能装。

下载后点开安装，如果提示"禁止安装未知来源应用"，按提示在设置里允许浏览器（或文件管理器）安装未知应用即可。

请只从 GitHub Releases 下载，应用商店里名字相近的应用和各种"中文版下载站"都无法确认来源。

## 第二步：导入机场订阅

1. 在机场用户中心复制 **Clash** 格式的订阅链接。
2. 打开 Clash Meta for Android，点主页的「配置」。
3. 点右上角的「+」（新配置），选择「URL」（从 URL 导入）。
4. "名称"随便填，比如机场名字；"URL"粘贴订阅链接；"自动更新"可以填一个间隔（单位是分钟），比如 1440 就是每天更新一次。
5. 点右上角的保存图标，等它下载完成。
6. 回到配置列表，**点选刚导入的这份配置**（前面的圆点变成选中状态），它才会生效。

## 第三步：启动

1. 返回主页，点最上面的「已停止 / 点击启动」。
2. 第一次启动时，系统会弹出"网络连接请求"，询问是否允许建立 VPN 连接，点「确定」。
3. 状态变成「运行中」，状态栏出现钥匙图标，说明已经连上了。

## 第四步：选择节点

1. 点主页的「代理」，能看到机场配置好的节点分组。
2. 点进分组，选一个节点即可切换；页面上的闪电图标可以测延迟，优先选延迟低、没有超时的节点。
3. 代理页面的菜单里还可以切换「规则 / 全局 / 直连」模式，**日常用"规则"就行**，区别见[Clash 规则模式、全局模式与 TUN 模式详解](/tutorials/clash-proxy-modes-tun/)。

打开浏览器访问一个国外网站测试，能打开就说明配置成功。

## 分应用代理（可选）

如果只想让部分应用走代理，或者让银行类应用绕开代理，可以在「设置 → 网络 → 访问控制」里设置：

- **仅允许已选择的应用**：只有勾选的应用走代理。
- **不允许已选择的应用**：勾选的应用不走代理，其余都走。

不需要的话保持默认即可，规则模式下国内应用本来就会直连。

## 常见问题

**显示运行中，但网页打不开？**
先确认配置列表里选中了正确的配置；再到「代理」页测一下延迟，换两三个节点试试；最后检查手机上是不是同时开着其他 VPN 或加速器，同一时间只能有一个 VPN 生效。

**订阅更新失败？**
检查链接是否完整、是否过期、复制的是不是 Clash 格式；也可以切换到手机流量再更新一次。更多排查思路见[常见问题排查](/tutorials/common-connection-problems/)。

还没选好机场的话，可以先看[机场推荐排行榜](/rankings/)；其他平台的客户端见[Clash 教程与客户端推荐](/clash/)。
