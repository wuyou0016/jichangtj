刚用 Clash 的人经常被两组开关搞混：一组是「规则 / 全局 / 直连」，另一组是「系统代理 / TUN 模式」。其实它们管的是两件不同的事：

- **系统代理 / TUN**：决定流量**怎么进入** Clash。
- **规则 / 全局 / 直连**：决定流量进入 Clash 之后**走不走代理**。

两组设置可以自由组合，大多数人用「规则模式 + 系统代理」就够了。

## 规则、全局、直连：流量进来之后怎么走

### 规则模式（推荐日常使用）

Clash 按订阅里自带的规则逐条匹配每一个连接：比如国内网站、国内 IP 直连，Google、YouTube 等走代理节点，广告域名直接拦截。好处是：

- 国内网站不绕路，速度不受影响；
- 国内流量不消耗机场流量；
- 部分只允许国内 IP 访问的服务（比如一些视频网站的版权内容）也能正常使用。

规则由机场随订阅下发，更新订阅时规则也会跟着更新。

### 全局模式

所有流量都走你选中的那个节点，不看规则。适合的情况很少：

- **排查问题**：某个国外网站在规则模式下打不开，切到全局能打开，就说明是规则没覆盖到。
- 临时需要所有流量都从某个地区出去。

缺点是国内网站也要绕到国外再回来，变慢且消耗流量，部分国内服务还会因为检测到境外 IP 而限制使用。**用完记得切回规则模式。**

### 直连模式

所有流量都不走代理，相当于"客户端开着，但暂时不翻墙"。需要临时关闭代理又不想退出客户端时可以用。

## 系统代理、TUN：流量怎么进入 Clash

### 系统代理

Clash 把操作系统的代理设置改成指向自己。浏览器和大多数遵守系统代理设置的软件，流量会自动交给 Clash。

- **优点**：不需要额外权限，开关即时生效，和其他软件冲突少。
- **局限**：只对"愿意读取系统代理设置"的程序有效。不少游戏、命令行工具（比如 git、npm、pip 默认读取的是环境变量而不是系统代理）、部分桌面应用会绕过它；系统代理也不处理 UDP 流量。

### TUN 模式（虚拟网卡模式）

Clash 创建一块虚拟网卡，在网络层接管整台电脑的流量，不管程序是否遵守系统代理设置，包括 UDP 流量。

- **优点**：覆盖所有程序，游戏、命令行工具、各种客户端都能走代理。
- **需要注意**：开启需要管理员权限（Windows 上 Clash Verge Rev 需先安装服务模式，macOS 需输入密码授权）；和其他 VPN、加速器、公司内网 VPN 可能冲突，同一时间只开一个。

## 怎么组合

| 你的情况 | 推荐组合 |
| --- | --- |
| 日常上网、看视频、用浏览器 | 规则模式 + 系统代理 |
| 打外服游戏、用命令行工具、某个软件不走代理 | 规则模式 + TUN 模式 |
| 某个国外网站打不开，想确认是不是规则问题 | 临时切全局模式，排查完切回规则 |
| 暂时不需要代理 | 直连模式，或者直接关闭系统代理 / TUN |

打游戏还要注意：游戏大多使用 UDP，需要节点本身支持 UDP 转发，只开系统代理是不够的。游戏场景该关注的指标见[游戏加速机场推荐](/scenarios/gaming/)。

## 常见问题

**退出 Clash 之后电脑上不了网？**
这是系统代理没被还原：客户端异常退出时，系统代理仍然指向一个已经不存在的地址。重新打开客户端关掉系统代理再退出；或者手动关闭——Windows 在「设置 → 网络和 Internet → 代理」，macOS 在「系统设置 → 网络 → 当前网络 → 详细信息 → 代理」。

**开了 TUN 之后公司 VPN / 内网访问不了？**
两个虚拟网卡在抢流量。需要访问内网时先关掉 TUN，改用系统代理；或者在客户端里把内网网段设置为直连（需要一定配置经验）。

**命令行 git clone 很慢，好像没走代理？**
只开系统代理时，命令行工具通常不会走代理。可以开 TUN 模式，或者给终端单独设置代理环境变量。

更多连接问题见[常见问题排查](/tutorials/common-connection-problems/)，各平台客户端的具体操作见[Clash 教程与客户端推荐](/clash/)。
