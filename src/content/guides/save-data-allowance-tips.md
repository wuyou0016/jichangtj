## 先说结论

流量不够用，大多数情况下不是套餐本身有问题，而是三类习惯性消耗叠加在一起：

- **视频清晰度开得比实际需要的高**，流媒体和短视频是流量消耗大头；
- **系统和应用在后台自动更新、自动备份**，这部分流量经常在你没注意的时候就用掉了；
- **客户端用的是全局模式**，连访问国内网站的流量也一起走了代理，等于白白多算一遍。

把这三类控制住，很多人会发现套餐够用了，不需要立刻升级到更贵的档位。

## 常见耗流量行为和省流量做法对照

| 耗流量行为 | 为什么耗流量 | 省流量做法 |
| --- | --- | --- |
| 视频默认最高清晰度播放 | 清晰度每升一档，流量消耗明显增加 | 手动把默认清晰度调低一档，需要时再临时调高 |
| 系统 / 应用自动更新 | 大版本更新动辄几百 MB 到几 GB | 设置为仅在 Wi-Fi 下自动更新，或手动触发 |
| 云相册 / 网盘自动备份 | 拍照后立刻上传原图，常年后台运行 | 改为仅 Wi-Fi 下备份，或降低备份画质 |
| 客户端用全局模式 | 国内网站的流量也被算进代理流量 | 日常使用切到[规则模式](/glossary/#rule-mode)，只排查问题时临时切全局 |
| 多个设备同时挂着同一节点 | 后台应用在多台设备上分别消耗流量 | 不用的设备及时断开，参考[多设备与路由器](/knowledge/multi-device-and-router/) |
| 节点命中高倍率线路 | 部分节点按倍率折算，实际消耗比显示的流量更多 | 下单前确认[流量倍率](/glossary/#multiplier)，优先用倍率透明的节点 |

## 规则模式和全局模式的流量差异

这是最容易被忽略、但影响最直接的一项设置。规则模式下，客户端按照域名和地区规则分流：国内网站、常用国内应用走直连，不占用代理流量；只有规则判定需要代理的部分才会经过节点。全局模式则相反，所有流量不分青红皂白都走代理，相当于你平时刷的国内内容也被重复计算了一遍流量。日常使用建议默认开规则模式，只有排查"是不是分流规则导致某个网站打不开"这类问题时，才临时切到全局模式验证，确认之后记得切回来。具体客户端的设置位置，不同系统略有差异，可以参考[按设备选客户端](/knowledge/client-choice-by-device/)。

## 日常省流量习惯清单

<ul class="checklist">
<li>打开常用视频和短视频应用的设置，把默认清晰度调低一档，而不是每次手动调</li>
<li>检查系统和各个应用的自动更新设置，改成仅 Wi-Fi 下进行</li>
<li>关闭云相册、网盘的蜂窝数据自动备份，改为仅 Wi-Fi 上传</li>
<li>日常使用保持规则模式，不用的时候不要长期开着全局模式</li>
<li>不用的设备（旧手机、备用平板）及时退出客户端或断开连接</li>
<li>每隔几天看一次客户端自带的流量统计，定位某一天流量异常增长对应的是哪个应用</li>
</ul>

## 怎么找到真正的耗流量源头

多数主流客户端都自带流量统计功能，能按时间、有时还能按应用展示消耗明细。遇到流量下降明显变快的情况，先打开这个统计面板，而不是直接怀疑套餐或节点有问题：

1. 看最近几天的流量曲线，找出消耗明显变高的那一天或那几个小时；
2. 回忆那段时间在做什么：是不是在看高清视频、是不是手机系统刚推送了更新；
3. 如果找不到明显原因，检查客户端当前是不是开着全局模式，国内流量被重复计算是最常见的"找不到原因"的情况；
4. 排除以上几项之后流量依然消耗很快，再考虑是不是节点本身命中了高倍率线路，这部分可以对照官网的套餐说明核实。

## 学习和办公场景的流量特点

[学习查资料](/scenarios/study/)这类场景，单次打开网页、下载文献的流量消耗本身不大，但很容易被忽略的是：后台开着视频网站当背景音、下载课程的大体积压缩包或网盘资源、浏览器开了十几个标签页自动刷新，这些叠加起来并不比刷视频少多少。如果你发现自己明明"只是查资料"，流量却消耗得比预期快，可以先检查后台有没有同时开着视频或下载任务，而不是先怀疑套餐或节点。预算有限的学生党尤其值得养成这个检查习惯，省下来的流量比临时加购划算。

## 小结之前：一个常见的认知误区

有一种常见的想法是"流量不够用就是套餐太小"，但实际排查下来，很多情况是同一份流量被多台设备或多个后台任务重复消耗，而不是套餐本身设计不合理。先用上面的清单和流量统计面板做一轮排查，往往比直接升级套餐更快解决问题，也更不容易在升级之后又遇到同样的情况。

## 什么时候该换套餐，而不是继续省

省流量习惯能延长可用时间，但不能无限压缩。如果你已经把清晰度、自动更新、全局模式这几项都调整过，流量依然不够用，说明你的真实使用量就是比当前套餐大，这时候该考虑的是升级套餐或确认流量重置规则，而不是继续在习惯上抠。具体怎么把价格和流量换算清楚、怎么判断该不该升级，可以参考[机场价格怎么看](/knowledge/airport-pricing-explained/)里统一成"每月真实成本"的算法，再决定是否值得换一档。

## 小结

流量不够用，先排查习惯再决定要不要花钱。视频清晰度、自动更新、全局模式是最常见的三个大头，调整之后很多人会发现原来的套餐其实够用。确认习惯已经没问题、流量依然紧张，再去看套餐本身是不是该升级，这样花的每一分钱都花在真实需要上，而不是花在没注意到的后台消耗上。
