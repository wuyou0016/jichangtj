## 先说结论

不存在“所有人都该用的最好客户端”。客户端只是一个工具，你要的是它**能连上你的节点、持续有人维护、用起来顺手、来源可信**。

下面先讲通用的选择标准，再按设备列出常见的客户端类型。具体软件名称和版本会不断变化，列出的只是“常见类型”，不构成对任何一款软件的背书，**请以你实际看到的版本和官方发布页为准**。

## 四个选择标准

| 标准 | 为什么重要 | 怎么判断 |
| --- | --- | --- |
| 协议支持 | 节点用 VLESS、Hysteria2 等较新协议时，旧内核可能连不上 | 看项目说明支持哪些协议；了解节点协议见[协议速读](/knowledge/protocol-quick-guide/) |
| 维护状态 | 停更的软件不再修复问题，也不支持新特性 | 看项目最近一次发布的时间、更新频率 |
| 来源可信 | 山寨安装包可能夹带恶意程序 | 只从项目官方发布页或官方应用商店下载 |
| 易用性 | 配置复杂会增加出错和排错成本 | 先看是否有图形界面、是否有中文界面 |

## 按设备看常见类型

### Windows

常见的是基于 Clash 内核分支（如 mihomo）的图形客户端，以及 v2rayN 这类支持多协议的客户端。原版 Clash for Windows 已停止更新，不建议继续使用。选择时重点看：是否支持你的节点协议、是否有“TUN 模式”（让不遵守系统代理的软件也走代理）。

### macOS

常见的也是 Clash 内核分支的图形客户端，以及 sing-box 系的客户端。macOS 的权限与系统代理设置比较严格，首次使用时可能需要在“系统设置”里授权，按软件提示操作即可。

### iOS / iPadOS

常见的有 Shadowrocket、Stash、Loon、Quantumult X 等，多数是**付费软件**，并且可能需要特定地区的 Apple ID 才能在应用商店中下载。这类软件的可用性和价格会随应用商店政策变化，购买前先确认能下载、能退款，不要通过来路不明的“共享账号”安装。

### Android

常见的有 Clash 内核分支的安卓客户端、v2rayNG、sing-box 的安卓版本等。安卓设备注意两点：一是**电池优化**，要把客户端加入白名单，否则后台容易被系统关掉；二是安装包只从官方发布页下载。

### 路由器

在支持的路由器固件上，可以安装适配的代理插件，让整个家庭网络的设备都走代理。优点是设备多时统一管理，缺点是配置复杂、排错困难，也要留意服务商对设备数和路由器使用的规定，见[多设备与路由器](/knowledge/multi-device-and-router/)。

## 下载安全

客户端装在你自己的设备上，权限很高，所以**来源比功能更重要**：

1. 只从项目官方的发布页或官方应用商店下载；
2. 不要使用搜索结果里的“破解版”“绿色版”“汉化版”；
3. 注意区分名字相似的山寨项目，核对发布者和链接；
4. 下载后可以对照发布页提供的校验信息（如果有）；
5. 不要为了“更快导入”而把订阅链接交给不可信的在线工具。

## 导入订阅前后要做什么

**导入前：**

- 确认服务商支持你选的客户端，见[通用订阅与官方客户端](/knowledge/universal-subscription-vs-official-client/)；
- 确认系统时间准确（部分协议对时间敏感）；
- 记下客户端版本，出问题时方便排查。

**导入后：**

- 手动更新一次订阅，确认节点列表出现；
- 选一个节点测试连接，再开启系统代理或 TUN 模式；
- 先用“规则模式”，排查问题时再临时切到“全局模式”；
- 把订阅链接备份到你自己能找到的地方，但不要截图外传。

具体步骤见使用教程：[客户端与订阅导入](/tutorials/client-setup-and-subscription-import/)；连不上时看[排查指南](/tutorials/common-connection-problems/)。

## 常见问题的方向

| 现象 | 常见原因 | 先查什么 |
| --- | --- | --- |
| 导入后没有节点 | 订阅链接不完整、套餐过期、格式不兼容 | 重新复制完整链接，检查套餐状态 |
| 节点有但连不上 | 内核不支持节点协议、系统时间错误 | 升级客户端、校准系统时间 |
| 部分软件不走代理 | 软件不读取系统代理 | 开启 TUN 模式或在软件内单独设置 |
| 后台经常断线（安卓） | 电池优化杀掉了客户端 | 把客户端加入电池白名单 |

## 小结

挑客户端像挑任何工具：**先确认它能干活（兼容你的节点），再确认它靠谱（来源与维护），最后才是顺手与否**。选定之后别频繁更换，熟悉一款比反复尝试更有效。
