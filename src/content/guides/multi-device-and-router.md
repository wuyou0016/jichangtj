## 先说结论

多设备使用的核心问题只有两个：**同时能用几台**，以及**怎么分配最省事又安全**。

- 设备数限制是服务商的规则，购买前就该问清；
- 订阅链接共享有泄露和超限风险，不要随手转发；
- 路由器方案是“集中管理”的取舍，适合设备多、愿意折腾的人。

## 设备数限制：先问清再买

设备数限制指同一个订阅可以**同时在线**的设备数量（有的按连接数，有的按不同 IP 计算）。购买前要问清楚：

| 问题 | 为什么重要 |
| --- | --- |
| 同时在线的上限是多少 | 决定一份套餐能不能覆盖你的设备 |
| 是按设备、按连接还是按 IP 计 | 路由器、手机切换网络时可能被多算 |
| 超限时会发生什么 | 是踢下线、临时限制，还是封禁订阅 |
| 不同套餐上限是否不同 | 有的低价档位限制更严 |

本站收录的服务商里，设备数限制的资料大多未列出，请以官网说明和客服回复为准，并保存回复内容。

## 家庭共用：几种做法的对比

| 做法 | 优点 | 风险 / 缺点 |
| --- | --- | --- |
| 每台设备各自导入同一订阅 | 简单、各设备独立 | 受设备数上限约束 |
| 把订阅链接发给家人 | 省事 | 链接泄露风险；不小心转发出去难以收回 |
| 买多个订阅分开用 | 互不影响 | 成本更高 |
| 路由器统一接入 | 全家设备自动走代理 | 配置复杂，一台出问题全家受影响 |

一个折中的做法：**自己在每台设备上完成导入，而不是把链接发给别人**。这样链接始终在你手里，万一泄露也只需要重置一次。详见[订阅链接安全](/knowledge/subscription-link-security/)。

## 路由器方案：利弊与适用

在支持的路由器固件上安装代理插件后，连接这台路由器的所有设备都可以走代理。

**优点：**

- 设备多时统一管理，不用逐台配置；
- 一些无法安装客户端的设备（电视、游戏主机等）也能使用；
- 设备在家庭网络内无需再手动开关。

**缺点与注意：**

- **配置复杂**：需要刷写或使用支持的固件，设置规则和订阅，出错时排查难度大；
- **一荣俱荣、一损俱损**：路由器上的代理出问题，全家设备都受影响；
- **性能受限**：路由器处理器性能有限，高速连接或复杂规则可能成为瓶颈；
- **服务商规定**：有的服务商对路由器使用有限制，或把路由器后面的多个设备算作多个连接，购买前要确认；
- **隐私与安全**：路由器的管理界面和更新要保持安全，否则风险更大。

适合谁：设备很多、有一定动手能力、愿意花时间维护的用户。**不适合**只有一两台设备、追求省心的人。

## 多设备使用的小习惯

<ul class="checklist">
<li>在记录表里列出你所有的设备，核对总数是否在设备数限制内</li>
<li>手机和电脑分别用适合各自系统的客户端，见<a href="/knowledge/client-choice-by-device/">按设备选客户端</a></li>
<li>不在公共电脑上登录自己的账号或导入订阅</li>
<li>换了手机或重装系统前，先把订阅链接备份好，旧设备上的客户端记得清除</li>
<li>发现流量异常增长，先检查设备列表，必要时重置订阅</li>
</ul>

## 办公与出差场景的补充

在<a href="/scenarios/remote-work/">远程办公</a>和<a href="/scenarios/travel/">出差出境</a>场景里，多设备意味着“备份”：手机和电脑各配置一套，主力设备出问题时能立刻切换。但也要注意，**同时在线的设备总数不要超过限制**，否则恰好在关键时刻被踢下线。

## 小结

先搞清设备数，再谈怎么分配。能自己一台台配置，就不要转发订阅链接；设备实在很多，再考虑路由器方案，并做好“出问题时全家受影响”的心理准备。
